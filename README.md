# 🧮 Python Calculator Website

Welcome to the **Python Calculator Website** — a simple yet elegant web-based calculator built using **Flask** and **HTML/CSS**. This project is a perfect starting point for beginners looking to combine Python with web development. 🌐🐍

---

## 🚀 Features

- ➕ Addition, ➖ Subtraction, ✖️ Multiplication, ➗ Division
- 🖥️ Clean and centered responsive layout
- ⚡ Fast calculation with real-time result display
- 🎨 Simple but beautiful UI using HTML & CSS
- 🧠 Built using Python Flask backend

---

## 🛠️ Tech Stack

| Layer       | Technology     |
|-------------|----------------|
| 🧠 Backend   | `Python 3`, `Flask` |
| 🌐 Frontend | `HTML5`, `CSS3` |
| ⚙️ Server   | `Flask Development Server` |

---

📝 Code Overview

🔹 app.py
Handles routing, logic, and rendering the result based on user input.

🔹 index.html
Contains the form, layout, and style of the calculator.
